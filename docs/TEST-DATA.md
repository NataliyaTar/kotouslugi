## Быстрые API-команды (PowerShell)


## H2 Console — полезные запросы

> **PostgreSQL** (по умолчанию): `psql` или DBeaver → `jdbc:postgresql://localhost:5432/kotouslugi`, user `kotouslugi` / password `kotouslugi`  
> Поднять БД: `docker compose up -d` — см. [POSTGRES.md](./POSTGRES.md)

```sql
SELECT * FROM cat;
SELECT * FROM service WHERE mnemonic IN ('animal_passport', 'drug_registry');
SELECT m.name, d.trade_name, b.batch_code, b.status
FROM manufacturer m
JOIN drug d ON d.manufacturer_id = m.id
JOIN drug_batch b ON b.drug_id = d.id;
SELECT c.name, p.chip_number, p.kennel_name FROM cat c
LEFT JOIN animal_passport p ON p.cat_id = c.id;
```
