## Быстрые API-команды (PowerShell)

```powershell
# Список котов
Invoke-RestMethod http://localhost:8080/api/cat/list

# Список салонов
Invoke-RestMethod http://localhost:8080/api/grooming/salons

# Слоты салона на дату
Invoke-RestMethod "http://localhost:8080/api/grooming/slots?salonId=0&visitDate=2026-07-10"

# Отправка отзыва
Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/grooming/review -ContentType "application/json" -Body '{"appointmentId":1,"rating":5,"comment":"Отличный сервис"}'

# Список заявок
Invoke-RestMethod http://localhost:8080/api/requisition/list
```
